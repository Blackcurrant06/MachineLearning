# Machine Learning Coursework

This repository is an archive of assignments and projects completed for my college Machine Learning course. It documents my learning throughout the semester, from data exploration and preprocessing to classical machine learning algorithms and deep learning.

The coursework is organized by week, with separate folders for the midterm exam (**UTS — Ujian Tengah Semester**) and final exam (**UAS — Ujian Akhir Semester**). Most assignments are Jupyter notebooks containing code, explanations, visualizations, and saved results.

## Repository Structure

| Folder | Topics and Assignments |
| --- | --- |
| `Week1/` | Automobile price regression and heart disease classification |
| `Week2/` | Boston housing regression and Citarum water classification |
| `Week3/` | Income classification and infrared temperature regression using decision trees and KNN |
| `Week4/` | Data preprocessing, feature engineering, and analysis of flu and COMPAS datasets |
| `Week5/` | Exploratory data analysis and visualization of Netflix, Spotify, and Walmart sales data |
| `Week6/` | Clustering exercises using campaign, online retail, and other course datasets |
| `Week7/` | Ensemble learning with bagging and boosting for classification and regression |
| `Week8/` and `Week9/` | Placeholder folders retained from the course |
| `UTS/` | Midterm assignments comparing regression, classification, and clustering algorithms |
| `UAS/` | Final assignments covering TensorFlow and PyTorch neural networks for regression and classification, plus a TensorFlow CNN for image classification |

## Topics Covered

- Data cleaning, missing-value handling, and exploratory data analysis
- Feature engineering, encoding, scaling, and feature selection
- Regression and classification with linear models, decision trees, KNN, and support vector machines
- Ensemble methods, including random forests and boosting
- Unsupervised learning, clustering, and dimensionality reduction
- Neural networks using TensorFlow/Keras and PyTorch
- Model evaluation through metrics, comparisons, and visualizations

## Tools and Libraries

The notebooks primarily use **Python**, **Jupyter Notebook**, **pandas**, **NumPy**, **Matplotlib**, **Seaborn**, and **scikit-learn**. Individual assignments also use libraries such as SciPy, XGBoost, imbalanced-learn, statsmodels, TensorFlow/Keras, and PyTorch.

## Viewing the Coursework

Browse the weekly folders or exam folders and open the notebooks to review each assignment. Some datasets are included in the corresponding `Dataset/` folders; others were accessed through external sources or the original notebook environment.

Several notebooks use Google Colab or Kaggle paths, so running them elsewhere may require adjusting dataset locations and installing the relevant libraries. Saved outputs reflect the original coursework runs.

## Archive Status

The course has been completed. The assignments are preserved in their original submitted form as a record of my learning and experimentation during the semester. This repository is a coursework archive rather than a maintained machine learning application.
